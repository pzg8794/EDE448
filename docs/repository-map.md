# EDE448 Repository Map

The course repository is the public planning and navigation hub. Each major paper or submission package keeps its own Git history inside the matching assignment directory.

## Drive Root

Course materials and local source packets are organized under the EDE448 Drive materials folder: [EDE448 materials folder](https://drive.google.com/drive/folders/1pGIdniDMT7CMc8I7l6AOdTpq1oQtAhk6). Public GitHub repositories contain public-safe drafts and editable source, not raw copyrighted packets or private learner evidence.

The nested `repository/` directories are intentionally ignored by the outer course repository so their histories, remotes, and working trees remain independent. The portfolio's dedicated checkout is private and is the Overleaf authoring surface for the complete restricted package. Portfolio source-of-truth work stays in `portfolio/repository/`; identifiable images and restricted PDFs never enter the public course repository. The historical hyphen-named Sensory Walk repository is preserved on GitHub but is not treated as the canonical local checkout.

Dedicated assignment repositories that had been sitting outside the course tree were moved intact into their matching module assignment directories. Stale duplicate working copies were preserved outside the course tree under `DataScience/_repository-archives/EDE448-2026-08-02/`; no Git history or configured remote was deleted.
