# Module 3 Journal LaTeX Package

This editable package follows the visual structure used for the Module 1 and Module 2 journals.

## Files

- `main.tex`: cover page, framework statement, and document structure
- `sections/`: editable journal sections
- `references.bib`: course, prior-work, and applied-evidence references
- `main.pdf`: local compiled review copy; ignored by the public course repository

## Build

```bash
latexmk -pdf main.tex
```
